# Project Resolving Checklist

- [ ] Project key explicit, or inferred **and confirmed** with the user
- [ ] Profile loaded from the local profile directory, or bootstrapped live
- [ ] `verified` within 180 days, or drift checked for the fields in use
- [ ] Assignee resolved live — never guessed
- [ ] Active sprint resolved live, or omitted because the type says `omit`
- [ ] Parent present when the type `requires_parent`
- [ ] Every `field_rules` entry applied literally; notes collected
- [ ] Components handed back as the allowed vocabulary
- [ ] `create_call` sendable once summary, description and parent are filled
- [ ] Nothing created or edited by this skill
- [ ] Nothing written to disk without a yes, and never into a repo
