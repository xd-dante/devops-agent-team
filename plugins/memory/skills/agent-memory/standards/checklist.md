# Memory Checklist

## Recall
- [ ] Memory directories resolved; both scopes read where both exist
- [ ] `instructions.md` loaded and treated as user instruction
- [ ] Only relevant entries opened, chosen from index hooks
- [ ] Anything naming a file, branch or flag verified as still true
- [ ] Project/global conflicts surfaced, not silently resolved

## Remember
- [ ] The fact qualifies (`what-to-remember.md`) — not already in the code
- [ ] Checked the index for an entry that already covers it — updated rather
      than duplicated
- [ ] Correct scope chosen; project when unsure
- [ ] `**Why:**` present, and specific
- [ ] Dates absolute
- [ ] No secret value stored
- [ ] Index line added with a discriminating hook
- [ ] The user was told what was saved and where

## Suggest
- [ ] Offered, never saved silently
- [ ] Proposed text shown before writing
- [ ] Not offered more than once for the same fact

## Privacy
- [ ] Nothing from memory quoted into a commit, PR, doc, or this repo
- [ ] A project memory directory is gitignored in its own repo
- [ ] Any lesson promoted to a toolkit rule had its identifier removed
