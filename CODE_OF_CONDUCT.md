# Code of Conduct

## The short version

Be decent. Assume the other person is trying to help.

## Expected

- Keep discussion technical and specific. "This rule fails when X" beats
  "this is wrong"
- Accept that a maintainer may decline a change without it being a judgement
  on you
- Disagree with the argument, not the person

## Not acceptable

- Harassment, personal attacks, or discriminatory language of any kind
- Publishing someone's private information
- Deliberately derailing discussions, or repeatedly reopening settled
  decisions

## Scope

Issues, pull requests, discussions, and any other space representing this
project.

## Enforcement

Report a problem via GitHub's private vulnerability reporting, or by opening
an issue if it is not sensitive. The maintainer will respond as promptly as a
personal project allows, and may delete comments, close threads, or block
accounts.
